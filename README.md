
# 📊 Sorting Algorithm Tracer

An interactive web application for visualizing how different sorting algorithms work step by step. Designed as an educational tool, it helps students and developers understand the internal operations of popular sorting algorithms through animated execution.

---

## 🚀 Live Demo

## ✨ Features

* 📈 Step-by-step visualization of sorting algorithms
* 🎯 Interactive interface for learning sorting concepts
* ⚡ Smooth animations for each sorting operation
* 📚 Ideal for Data Structures & Algorithms (DSA) practice
* 💻 Fully browser-based — no installation required

## ⚙️ Getting Started

### Clone the repository

```bash
git clone https://github.com/sharonmedithi0304/sorting-tracer.git
```

```bash
cd sorting-tracer
```

Open **index.html** in your browser, or run the project using **Live Server** in Visual Studio Code.

---

## 🎯 How It Works

1. Choose a sorting algorithm.
2. Generate or load the dataset.
3. Start the visualization.
4. Watch each comparison, swap, and merge operation in real time.
5. Observe how the algorithm transforms the unsorted data into a sorted sequence.
